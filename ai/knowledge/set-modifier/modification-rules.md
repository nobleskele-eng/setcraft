# Set modification

First identify the original set’s likely objective, then preserve that objective while changing only what the request requires.

Check, in order:

1. athlete or lane restrictions;
2. course and available equipment;
3. total volume and high-intensity volume;
4. work-to-rest relationship;
5. stroke and technical loading;
6. the observable success measure.

State meaningful changes in volume, intensity or density. Never describe a modification as medical clearance. If the requested constraints make the original purpose unrealistic, say so and provide the closest safe programming alternative for coach review.
