# Modification order

1. Identify the original purpose.
2. Extract hard constraints from the coach request and athlete profile.
3. Identify which dose variables create the purpose.
4. Change the smallest number of variables needed.
5. Recalculate volume, high-intensity volume, and timing.
6. State what changed and what was preserved.
7. Add a coach check and stop rule.

# Hard versus soft constraints

Hard constraints include:

- coach-entered restrictions;
- unavailable or prohibited equipment;
- pool course and lane time;
- maximum session distance or duration;
- prohibited strokes or movements;
- safety and safeguarding requirements.

Soft constraints include preferred variety, favorite equipment, or a requested format that can change while preserving the objective.

# Preserve the objective, not the appearance

An aerobic set can remain aerobic when stroke, equipment, or repeat length changes, provided sustainable work, density, and technical control remain comparable. A speed set cannot be preserved by simply keeping the same total distance with less rest; the velocity and recovery relationship matter.

# Modification levers

- change stroke while preserving energy-system and skill intent;
- change repeat distance while preserving total quality time;
- change repetition count while preserving the intended dose;
- change rest or send-off to preserve velocity or sustainable density;
- replace equipment with a body-position or technical cue;
- replace full stroke with drill/swim or another stroke under a restriction;
- use time-based work for mixed-course or mixed-ability settings;
- split a long block into rounds with feedback opportunities;
- reduce volume before adding intensity to compensate.

# When the original purpose cannot be preserved

Say so directly. Examples:

- a maximal butterfly-power set cannot remain butterfly-specific when butterfly is prohibited;
- a dive-start session cannot be replicated without safe start access;
- a race-pace target may be unrealistic after a large restriction-driven change;
- a planned load may not fit the remaining lane time.

Offer the nearest purpose that is feasible and label it as changed.

# Output format

Return:

1. revised LaneLab Quick Write set;
2. original purpose;
3. constraints respected;
4. distance and intensity changes;
5. what may no longer transfer;
6. coach check.

Never claim the revised set is safe for an injury, provides medical clearance, or replaces rehabilitation advice.
