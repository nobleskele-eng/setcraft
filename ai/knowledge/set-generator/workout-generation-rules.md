# Workout generation

Every generated set should make the training purpose visible. Use SetCraft Quick Write syntax, calculate the requested distance exactly, and separate preparation, main work and recovery when appropriate.

For each important block, include:

- repeat count, distance, stroke and send-off or rest;
- intended effort or pace target;
- one observable technical cue;
- a quality-control rule the coach can observe;
- equipment only when it supports the objective and is permitted.

Send-offs must be treated as drafts until compared with actual lane completion times. Avoid stacking high-intensity work merely to reach a distance target. Use recovery that protects the stated objective. When lane count, ability range or restrictions are missing, state the assumption and give the coach a simple adjustment rule.
