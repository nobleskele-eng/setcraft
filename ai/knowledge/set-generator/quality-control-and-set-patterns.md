# Pattern rule

The examples below are structures, not ready-to-assign prescriptions. SetCraft must fill pace, send-off, volume, and equipment from the athlete and lane context, then calculate total distance exactly.

# Pace-window pattern

Use when repeatability matters.

```text
# Main — pace repeatability
NxDistance Stroke @ lane-adjusted send-off — hold verified target ± coach-set tolerance
Quality rule: stop or reset after K misses or visible technical failure
Coach check: compare completion time, recovery, and stroke metric
```

# Broken-race pattern

Use to rehearse race segments with planned recovery.

```text
# Broken event
Segment 1 @ target checkpoint
fixed recovery
Segment 2 @ target checkpoint
...
Record: each segment, cumulative modeled total, and execution cue
Boundary: broken total is not an official swim time
```

# Speed-quality pattern

Use for maximal or near-maximal velocity.

```text
# Speed
Low count of short efforts from a named start
Full or near-full recovery
Measure: fixed-distance time plus one technical variable
Stop rule: velocity loss beyond the coach's limit
```

# Turn-quality pattern

```text
# Turn segment
Repeated fixed boundary, such as 5 m in to 10 m out
Measure: segment time, approach consistency, push-off line, breakout
Recovery: enough to repeat the intended speed
```

# Aerobic technical pattern

```text
# Aerobic skill
Moderate repeat duration at sustainable effort
One stroke or body-line focus
Measure: even pace plus stroke-count or technical band
Adjustment: shorten repeat before allowing repeated technical failure
```

# Descending pattern

A descend is useful only when the start, finish, and size of the change are clear. Specify whether the athlete descends time, effort, stroke count at maintained speed, or another metric.

# Best-average pattern

Use sparingly and define recovery. Best average encourages high repeated output; it is not a label for every hard set. Compare within consistent conditions and stop when the task no longer represents the intended speed.

# USRPT-style pattern

Race-pace repetitions with brief recovery and failure rules may be useful in some programs. Present USRPT as one method, not settled universal doctrine. Define the target pace, repeat length, recovery, failure rule, event, athlete level, and placement in the program. Do not call every short-rest race-pace set USRPT. Source anchor: PMID 39195603.

# IM transition pattern

Use short blocks around stroke changes and legal turns. Score the transition as well as the swimming. Avoid letting the fastest stroke erase evidence from the weaker transition.

# Equipment rules

- Equipment must serve the objective.
- Fins can change speed, kick demand, body line, and lane spacing; they do not make a set automatically easier.
- Paddles alter force demand and must respect entered restrictions and coach policy.
- Snorkels can reduce breathing disturbance but also change head position and awareness.
- Pull buoys change body position and load distribution.
- Parachutes, cords, and resisted systems require appropriate supervision and facility practice.

Never add equipment not requested when the test expects a restricted equipment list.

# Distance accounting

Calculate every block and the exact session total. If choice creates a variable distance, state the range. Do not claim a requested 1,200 m/yd block if the written repetitions sum to another number.

# Coach review checklist

- Purpose visible?
- Course and units correct?
- Exact distance correct?
- Send-offs possible for the lane?
- Recovery matches the objective?
- Equipment available and permitted?
- Restrictions respected?
- Quality and stop rules observable?
- Warm-up and cool-down proportionate?
- High-intensity load appropriate within the week?
