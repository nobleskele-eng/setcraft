# Causal restraint

A split pattern does not prove a physiological or technical cause. Use a hypothesis ladder:

1. observation supported by data;
2. plausible interpretations;
3. evidence for and against each;
4. next test or video angle;
5. provisional coaching action.

Avoid claims such as:

- "lactate failure" from a late-race slowdown;
- "poor aerobic system" from one swim;
- "weak legs" from a slow turn without video;
- "bad technique" from stroke count alone;
- "mental weakness" from pacing;
- injury risk from body size or self-rating.

# Mandatory uncertainty language

When any checkpoint is modeled or estimated, say the analysis is **limited** at those points. Identify which conclusions still rely on measured evidence and which require confirmation.

When no video exists, do not attribute time loss to a specific technical action. Recommend a targeted video capture.

When only one race exists, compare within the race and label between-race conclusions preliminary.

# Video capture protocol

For repeatable comparison, record:

- pool course and lane;
- camera position and height;
- frame rate;
- visible distance marks;
- start and endpoint definition;
- above-water or underwater view;
- event, start type, and trial condition;
- whether the footage is competition or training.

Useful views:

- side view for start, free-swimming timing, and breakout;
- end view for entry/catch symmetry and wall alignment;
- underwater side for line, kick, pullout, and breakout;
- elevated view for path and lane position.

Protect athlete privacy and follow facility policies.

# Turn review sequence

1. approach velocity and final strokes;
2. distance and timing to wall action;
3. contact or rotation;
4. foot placement and push direction;
5. streamline and depth;
6. underwater speed;
7. breakout timing;
8. first cycle connection.

Choose one limiting phase. Faster rotation with a worse push may not improve the whole turn.

# Start review sequence

1. setup consistency;
2. response to signal if timing exists;
3. block force/timing only if measured;
4. flight direction;
5. entry line;
6. underwater speed and depth;
7. breakout;
8. first cycle.

Compare fixed-distance time and repeatability. Do not optimize the block phase in isolation.

# Stroke metric cautions

- Stroke count without speed can reward gliding.
- Stroke rate without distance per cycle can reward spinning.
- Distance per stroke without timing can reward slowing down.
- Intracycle velocity variation is complex and should not be reduced to one universal ideal.

Use multiple measures and event context. Source anchor: PMID 36978699.

# Prioritized output

Return no more than three main findings unless the coach asks for depth:

1. highest-confidence performance finding;
2. largest controllable opportunity;
3. next discriminating check.

Keep locked SetCraft points, times, and provenance unchanged.
